# aprendizaje_por_refuerzo

Expo aprendizaje por refuerzo:

1. Definir que es Aprendizaje por Refuerzo, desde un punto de vista mediana mente conceptual y medianamente técnico. Partir del Aprendizaje Supervisado y No Supervisado. Hablar de sus componentes principales.
2. Explicación con ejemplos cotidianos (ejemplo del perro).
3. Demostración: demo de carrito 2d donde se pueda ver realmente el funcionamiento del aprendizaje por refuerzo. Tener en cuenta episodio por episodio, estado que ve el carro, exploración vs explotación.
